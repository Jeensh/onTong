3 가지 불가침 원칙

  1. Agent 는 온톨로지 Core 의 internal 모델을 직접 import 하지 않는다. Query API 만 통한다.
  2. Agent 추가/제거가 Core 에 영향 0. Agent 폴더 통째 삭제해도 온톨로지는 그대로.
  3. 한 Agent 의 데이터는 그 agent 의 store 에만 있다. Core 의 SQLite 에 끼어들지 않음.
