6. 다음 단계 (W74+ 후보)

  1. W74 — Sandbox stub injection layer: NAMERROR 7건 의 직접 해결. Section 2 의 인터뷰 결과 (term ↔ Java class 매핑) 를 가져와 stub 객체를 sandbox namespace 에 자동 주입. 핵심 method 만 mockable Stub 으로 시작.
  2. W75 — Java String idiom rewrite: ATTRERROR 2건 + 향후 추가 idiom. Translator 의 post-processing 으로 .length() → len(...), .charAt(i) → [i], .equals(...) → ==, .size() on Collection 등.
  3. W76 — Production baseline 수집 자동화: 현재 W73 의 baseline 은 수동 annotation. 실제 Java 의 record/replay 시스템 (e.g., AspectJ bytecode instrumentation) 으로 라이브 production trace 를 JavaBaselineMap 으로 import.
중요한 한계 표기: W74-W76 은 framework redesign 이 아니다. Two-Engine architecture / Schema layer / Detect-Fix loop / Lifecycle — 모두 redesign 없이 그대로 사용. translator depth + sandbox surface 의 incremental work 만 남았다.
