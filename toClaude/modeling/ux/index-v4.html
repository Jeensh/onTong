Lens 시스템 (팔란티어 dynamic styling 차용)

같은 그래프, 다른 의미 — 4 lens 동시

  • Verification lens (default) — 노드 색 = level (UNMAPPED 빨강 / DRAFT 노랑 / BODY_ANCHORED 파랑 / SIM_VERIFIED 초록 gradient)
  • Domain lens — 색 = 도메인 (4 색)
  • Confidence lens — 엣지 굵기 = realization confidence
  • Simulation hot lens — 노드 크기 = 시뮬 hot path 빈도 (A2 plug 시 활성)

한 그래프 = 여러 의미 layer. 단일 시각으로 multi-dimension 정보 전달.

Search Around (팔란티어 차용)

노드 우클릭 → context menu

  • ⊕ X-hop dependencies (forward 영향 받는 곳)
  • ⊖ X-hop dependents (backward 의존하는 곳)
  • 📖 관련 매뉴얼 fragments
  • 📁 영향 받는 코드 위치
  • ★ Path-trace 양방향
  • 🔧 Backward 모드로 (변경 가설 시작)

hierarchical drill-down 만이 아니라 point-and-click 으로 즉시 sub-graph.
