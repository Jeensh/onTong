V5 의 새로운 Mode 시스템 — 핵심 아이디어

중앙 Main 영역이 3 가지 mode 사이 토글:

  • Detail (default) — V1 Action 카드 sectioned. "이 Action 이 어떤 모양?" 탐색
  • ↕ Split — V2 차용. 위 Java body / 아래 Action card. "literal 클릭하여 매핑" 작업 모드
  • 🌐 Graph — full-screen takeover. "이 Action 의 의존 / Term 트리 / 호출 chain"

Detail / Split 사이 토글은 한 click. Graph 는 별도 mode (esc 로 빠져나옴) — 사용자 메모 "별도 화면" 정합.

대표 시나리오 (S3 anchor 매핑) 흐름

  1. 좌측 Action 트리에서 주문_검증 선택 → 중앙 Detail mode
  2. Anchor Bindings 섹션 — "⚠ 2 unconfirmed → ↕ Split mode 로 매핑" 버튼 클릭
  3. 중앙이 Split mode 로 전환 — 위 Java body, 아래 Action card
  4. 위 코드의 200.0 highlight 클릭 → "params[0]<RushOrder>.spec.diameter.range[1] AI 84%" tooltip + 확정 버튼
  5. 확정 → 진척 자동 갱신 (status bar 의 SL→BA 카운트 업데이트)
  6. 다음 unconfirmed anchor 자동 highlight
  7. 전부 처리 → 자동 Detail mode 복귀
  8. "이 Action 이 다른 거랑 어떻게 엮여있지?" 궁금 → 🌐 Graph 버튼 → full-screen 그래프 모드
