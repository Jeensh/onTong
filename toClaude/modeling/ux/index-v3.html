  1. 탭 바에서 "C 함량 변경 영향" 탭 활성

    • 📋 영향 Action 6개 (주문_검증 / 화학성분_검증 / 품질_평가 ...)
    • 📁 영향 Code 14 위치 (RushOrder.validate:11 ...)
    • 📜 업데이트 Rule 2개 (rule.scm.c_range)
    • 📖 매뉴얼 fragment 2 (slab-design §3.2 ...)
  5. Java 코드 변경 preview 자동 — diff highlight 로 0.25 → 0.30
