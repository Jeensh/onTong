4. Phase 13c 가 추가해야 할 것 (QA 우선순위)

  1. hypothesis intent 신설 — "X 가 Y 값일 때 Z 되나?" 패턴 인식. 숫자/단위/연산자 (<, =, ≥) 가 query 에 보이면 hypothesis 로 우선 라우팅.
  2. boundary value 추출 필드 — search_terms 외에 conditions: [{var, op, value, unit}] 분리. 예: [{var:"thickness", op:"=", value:0.1, unit:"mm"}]. Gate III sim 에 fixture 로 주입.
  3. conditional execution oracle — 추출한 condition 으로 Gate III sim 의 fixture 생성 → sandbox 실행 → "이 입력일 때 return = fail('XXX_001')" 형태로 응답. method body 던지기 X.
