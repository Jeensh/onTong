가설 검증 — SSE 스트리밍 4-step

  • Stage 1 기존 데이터 분석 — seed SD_PRODUCTIVITY_STD 의 SS400 row 8건
  • Stage 2 가상 강종 합성 — multiplier ×0.95 적용 row 8건
  • Stage 3 가상 주문 — base_order_no 4 table (OS/OM/QD/CHEMICAL) 복제 + ORDER_QD.GRADE_CD 만 변경
  • Stage 4 Slab 결과 비교 — Java :8080 실제 호출 baseline + projection (productivity 비율 적용)
  • "▶ SSE stream" 버튼으로 400ms 간격 progressive 등장
