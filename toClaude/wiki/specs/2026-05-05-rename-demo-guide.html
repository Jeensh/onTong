위키 Rename / 삭제 / 경로 변경 — 데모 가이드

2026-05-05 · 현재 동작 (baseline) + Phase 0 회귀 확인 + Phase 1~6 가 무엇을 고칠지 명시 · 사용자 직접 수행 · 결과 기록 후 마크다운 복사

⚠️ 중요 전제

Phase 0 는 인프라 추상화 (Profile / 백엔드 팩토리 / Postgres 스키마 / Arq / Redis 어댑터) 만 했고, 실제 rename·delete·move 로직은 변경 없음입니다.

이 데모는 다음 두 갈래 동시 검증:

  • ① 현재 rename/delete 의 알려진 깨짐 직접 재현 (라운드 1 의 가설 H1~H16)
  • ② Phase 0 변경 후 기능 회귀 없음 확인 (편집 락, 검색, 그래프, SSE)

각 시나리오의 BUG (현재) 표시 = 의도된 깨짐 (Phase 1~6 에서 수정). OK = 정상 동작 (Phase 0 후에도 유지).
