# slab 설계 엔진 (Slab-Design)

## 주요 플로우
### 1) slab 설계 대상 주문 추출
- 1) 주문정보 DB에서 추출
    - 주문 데이터는 GLOrder라는 도메인 객체에 아래 4개 테이블 값를 담아서 사용
    JPO들 -> Entity로 통합하여 feature에서 사용
        - ORDER_OS : 진행관리 주문 데이터
        - ORDER_OM : 주문처리 주문 데이터
        - ORDER_QD : 품질설계 주문 데이터
        - ORDER_CHEMICAL : 주문 성분 데이터
    - 저 데이터들을 JPO Join으로 가져오되, 몇가지 조건을 걸어서 가져옴
        - OS진도(진행정보)가 C, D 인것
        - CLOSE_FLAG(진행정보)가 1, 2가 아닌 것 (1: 종결, 2: 보류)
 - 2) 설계대상 주문 정합성 점검
    - 점검항목 :
        - 재고주문여부
        - 주문폭/주문길이
        - 포장단중범위
        - 설계대기량
        - 작업기한일 유무 등
  - 3) 설계 대상 주문 분류
    - Coil
    - 외판 등
    - 데모에서는 Coil만 가지고 함

### 2) slab 설계 (Coil)
 - 1) slab 두께 결정
    - 주문 스펙별 제강/연주 공장 설비의 생산 가능 두께 산정
    - 사용 기준
        - 연주설비사양기준
 - 2) 1차 설계가능 폭범위 산정
    - 연주 제조가능 폭범위,
      열연 제조가능 폭범위
      열연edging능력 범위, 주문의 열연목표폭을 고려해서 공통 폭범위 산정
      - 폭하한 = max(연주설비하한폭, 열연설비하한폭, 열연목표폭+열연edging능력하한)
      - 폭상한 = min(연주설비상한폭, 열연설비상한폭, 열연목표폭+열연edging능력상한)
    - 사용 기준 
        - 연주설비사양기준
        - 열연설비사양기준
        - 열연Edging능력기준
        - 열연Edging그룹기준
 - 3) 1차 설계가능 길이범위 산정
    - 연주제조가능길이범위,
      열연제조가능길이범위 고려하여 공통 길이범위 산정
        - 길이하한 = max(연주설비하한길이, 열연설비하한길이)
        - 길이상한 = min(연주설비상한길이, 열연설비상한길이)
    - 사용 기준
        - 연주설비사양기준
        - 열연설비사양기준
 - 4) 1차 설계가능 단중범위 산정
    - 1차 설게가능 폭, 길이범위를 고려하여 Size제약에 의한 설계가능 단중 범위 산정
        - 단중 하한 = 1차두께 * 1차설계범위하한 * 1차설계길이범위하한 * 비중
        - 단중 상한 = 1차두께 * 1차설계폭범위상한 * 1차설계길이범위상한 * 비중
 - 5) 2차 설계가능 단중하한 산정
    - 단중하한 = max(1차단중범위하한, 특정고객사설계제한단중하한, 압연Min단중)
    - 사용 기준
        - 열연설비사양기준
        - 압연Min단중기준
        - 특정고객사설계제한기준
 - 6) 2차 설계가능 단중상한 산정
    - 단중상한 = min(1차단중범위상한, 압연max단중상한, 특정고객사설계제한단중상한, 실수율고려설게대기량상한)
    - 사용 기준
        - 열연설비사양기준
        - 압연MAX단중기준
        - 특정고객사설계제한기준
 - 7) 최대분할수 산정
    - 2차 slab단중 설계범위와 주문단중 범위의 배수에 공통으로 만족하는 최대 분할수를 최대분할수 상한 값 내에서 결정
    - 최대분할수상한 = 소수점절상(2차설계가능단중상한 / 주문단중상한 / 실수율)
    - A-a : step 8~15까지 최대분할수 1씩 감소하면서 최종Slab설계시까지 반복
 - 8) 분할수 고려 최적분할수, 단중범위 계산
    - (주문단중 범위 * 분할수)와 2차 slab단중 설계범위간 공통 단중범위 산정하여 최적의 분할수 및 단중범위 계산
    - 단, 주문단중 범위 = 주문단중 상,하한 / 생산 실수율
    - 최적분할수 : slab단중 최대화를 목적식으로 삼아 나온 분할수
 - 9) 분할수고려 slab매수 산정
    - 매수 = 소수점절사(설계대기량상한 / 실수율 / 분할수고려단중범위상한)
 - 10) 분할수고려 slab단중 산정
    - slab단중 = 분할수고려단중범위상한
    - 분기) 설계대기량 만족? (slab단중 * 매수가 설게대기량범위(실수율고려)를 만족하는지 점검)
        - YES : 11번 이동
        - NO : 12번 이동
 - 11) 목표 Slab단중 및 매수 결정
    - slab단중 = slab고려 slab단중(step 10)
    - slab단중범위 = 분할수고려단중범위(step 8)
    - slab매수 = 분할수고려 slab매수(step 9)
    - 16번으로 이동
 - 12) 분할수고려 Slab 매수 1증가
    - step9에서의 slab매수를 1증가
 - 13) 분할수고려 Slab 단중 산정
    - slab단중 = 설계대기량상한 / 실수율 / slab매수
    - 단중정합성 : step 13에서 구한 slab단중이 step 8의 단중범위를 만족하는지 점검
    - 설계대기량 : step 13에서 구한 slab단중 * 매수가 설계대기량범위(실수율고려)를 만족하는지 점검
    - 분기) 단중정합성, 설계대기량 만족?
        - YES : 15번 이동
        - NO : 14번 이동
 - 14) 단중결정방법 변경
    - 단중결정방법을 제품단중최대화로 변경
    - A-a로 이동
 - 15) 목표 Slab단중 및 매수 결정
    - slab단중 = slab고려 slab단중 (step 13)
    - slab단중범위 = 분할수고려 단중 범위 (step 8)
    - slab매수 = 분할수고려 slab 매수 (step 12)
 - 16) 최종 Slab 폭 범위 산정
    - slab폭하한 = slab단중 / (1차설계길이상한 * slab설계두께 * 비중) [1자리 올림]
    - Slab상하한 = slab단중 / (1차설계길이하한 * slab설계두께 * 비중) [1자리 내림]
    - slab단중 : step11 또는 15의 slab단중값
 - 17) 최종 Slab길이범위 산정
    - slab길이하한 = max((slab단중 / (최종설계폭상한 * slab설계두께 * 비중)), 1차길이하한)
    - slab길이상한 = min((slab단중 / (최종설계폭하한 * slab설계두께 * 비중)), 1차길이상한)
    - slab단중 : step 11 또는 15의 slab단중값
 - 18) 목표 Slab폭 계산
    - 목표slab폭 = (10mm단위올림단위) 분할수 고려 slab단중상한 / (최종slab길이상한 * slab두께 * 비중)
    - 단, 위의 게산값이 최종 slab폭 범위를 벗어나면, 목표slab폭 = 최종slab폭범위하한
 - 19) 목표 Slab길이 계산
    - 목표Slab길이 = (1단위 내림처리)목표slab단중 / (목표slab폭 * slab두께 * 비중)
 - 20) slab설계결과 테이블에 설계결과 저장
 - 21) step별 설계과정 history 테이블에 저장

## 사용 테이블
- ORDER_OM : 주문정보 (주문처리)
- ORDER_OS : 주문정보 (진행관리)
- ORDER_QD : 주문정보 (품질설계)
- ORDER_CHEMICAL : 주문정보 (성분)
- SLAB_RESULT : Slab설계 결과 정보
- SLAB_DESIGN_HIST : slab설계 과정 이력
- CAST_SPEC : 연주설비사양기준 정보
- HR_SPEC : 열연설비사양기준 정보
- EDGING_SPEC : Edging능력기준 정보
    - EDGING_GROUP과 연결
- EDGING_GROUP : Edging능력그룹 정보
- CUSTOMER_STD : 특정고객사 설계 제한
- HR_MAX_WGT : 압연MAX단중기준 정보
- HR_MIN_WGT : 압연MIN단중기준 정보

## 도메인적 주요 참고사항
- 하나의 Order로 여러 Slab가 나올 수 있음
    - 현재 주문의 설계 대기량 정보에 따라 slab 설계
- 하나의 slab는 1개의 주문만 담고 있음
- 단중은 중량을 의미함
- 분할수는 1개의 slab에서 몇개의 제품이 나오는지를 말함

## 개발시 주요 참고사항
- JPO : @Entity가 붙은 클래스를 의미 (JPA에서 사용)
- Entity : feature에서 사용하는 도메인 클래스를 말함 (단일 JPO or 복수 JPO를 가지고 만듬)
- JPO -> Entity로 값 이전시, 리플렉션 기능 사용, 일부는 직접 계산해서 넣을 수도 있음
- 주요 작업 클래스 (SDOrder, SDSlab)두 Entity는 DB에서 가져온값을 담는 필드와 실제 작업용 필드(런타임중 메모리에 담아놓고 사용하는 용도)를 별도로 분리해서 선언하고 사용함
- 비중은 원래는 기준이 있으나 일단은 Service에서 가져온다고만 생각하고 7.82로 고정
- 실수율도 원래 계산하는 엔진과 저장하는 기준이 따로 있으나, 비중처럼 일단은 service에서 가져온다고만 생각하고 적당히 넘겨줄 수 잇는 로직을 작성할 것
