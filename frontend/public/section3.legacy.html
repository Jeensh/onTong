@dataclass

7-3. 파싱 흐름

1. tree_sitter_java.language() 로 Language 객체 1회 생성 2. JavaMethodInfo dataclass 로 통합

✅ 됨. 기존 자바를 tree-sitter 로 읽고, LLM 이 같은 의미의 Python 으로 변환하고, 그 Python 을 안전 격리(subprocess + setrlimit) 안에서 실제 입력값으로 굴린다. "HR 실수율 0.95 → 0.92" 같은 룰 변경을 코드 수정 없이 입력으로만 바꿔 결과 확인 가능 (§10-1, §10-3).

② 실제 자바와 결과가 같은지 매번 확인할 수 있다

✅ 됨. 같은 입력을 자바(slab-design Spring Boot @ :8080) 와 Python (onTong) 양쪽에 동시에 넣고, 결과의 모든 필드를 평면화(flatten)해서 1:1 비교. 숫자는 BigDecimal 오차 허용. 오늘 실측: matched 18 / mismatched 15 (§10-6).

③ "이 룰을 바꾸면 어떤 step 이 영향받지?" 처음 보는 사람도 답한다

✅ 됨. "실수율" 한 단어 검색 → 영향 step 8개 + 추천 시나리오 2건 자동 응답 (§10-5 OntologyBridge). 한국어/영문/컬럼명 alias 16개 자동 정규화. AI 어시스턴트(자연어) 진입로도 별도 제공.

④ 한 번 검증한 결과를 "정답"으로 박제하고 회귀를 자동으로 잡는다

✅ 됨. 실행 이력 (§10-4) 의 별 클릭 → baseline 박제 → 같은 시나리오 재실행 시 regression_diff 자동 계산. 오늘 추가: "▶ 상세" 버튼으로 input/output JSON 즉시 펼침 + 재실행 비교 화면에서도 baseline/candidate 원본 JSON 양쪽 동시 노출.
