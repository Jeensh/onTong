0. slab-design 시스템 — 무엇을 하는 시스템인가

제철소의 slab 설계 (Slab Design) 알고리즘 데모 시스템. 고객 주문 1건이 들어오면 21단계 알고리즘으로 적절한 slab (강편) 의 두께·폭·길이·매수·중량을 자동 산정합니다.
이 onTong Section 3 의 분석 대상 (legacy 자바 fixture) 으로, Java/Spring Boot 21-step 알고리즘 + Oracle/Kafka 의존 구조를 의도적으로 보존.

도메인

제철소 SCM
제강(SM) → 열연(HR) → slab 설계

알고리즘

21-step
검증 + 룩업 + A-a 루프 + 최종

DB 테이블

14종
주문 4 + 표준 8 + 결과 2

스택

Java 21
Spring Boot 3.4 / JPA / H2

🚨 알고리즘 fail 코드 (DG10x ~)

코드step의미
DG101step 1CAST_SPEC(연주설비 사양) 미존재 — 슬랩 두께(slabThickness) 결정 불가
DG102step 2HR_SPEC(열연설비 사양) 미존재 또는 HR 비활성 — 폭(firstWidth*) 산정 불가
DG103step 2EDGING_GROUP(Edging 그룹기준) 매칭 실패
DG104step 2산정된 폭 범위 invalid (firstWidthLow(폭하한) > firstWidthHigh(폭상한))
DG106step 5/6단중 산정 invalid — HR_MIN_WGT(압연 MIN 단중) 격자 외 또는 secondWgtLow(단중하한) > secondWgtHigh(단중상한)
DG108step 12-13A-a 루프 silent fail — 분할 단중 범위(splitWgt*) 또는 매수(slabCount) 미수렴
DG109step 8A-a 루프 분할수 maxSplit~1 까지 모두 수렴 실패 (no convergence)

  1. 새 Request 생성 → Method = POST

  3. Headers 탭 → Content-Type = application/json
