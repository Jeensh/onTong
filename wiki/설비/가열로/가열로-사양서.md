# 가열로 사양서 — DG-320

> 한성메탈 2공장 3라인 가열로 기본 사양. 온도 운전 기준은 [[가열로-온도-프로파일]]을 참조.

## 설비 개요

| 항목 | 값 |
| ---- | -- |
| 모델 | DG-320 |
| 제조사 | 대림정공 |
| 도입 연도 | 2019년 |
| 위치 | 2공장 3라인 북측 |
| 설비ID | EQ-HTR-DG320-03 |

## 기본 제원

- 최대 온도: **250℃** (연속 운전 상한 220℃)
- 유효 가열 공간: 2,400 × 1,500 × 1,800 mm (W×D×H)
- 소비 전력: 320 kW (정격)
- 열원: 전기 저항 히터 6뱅크
- 온도 센서: PT-100 × 8 (Zone 1~4 각 2계통)
- 제어: Siemens S7-1500 PLC + WinCC HMI

## 운전 기준

일반 운전은 [[가열로-온도-프로파일]]의 현행 승인본을 따릅니다.
고온 작업 시 [[안전표준-고온작업]] 준수 필수.

## 일상점검
- 매 교대 시작 시 PT-100 센서 편차 확인 (2℃ 이상 시 조치)
- 주간 히터 뱅크 저항 측정
- 월간 내화물 크랙 점검
