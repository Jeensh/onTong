# 단조프레스 일상점검 — FP-210

> 매 교대 시작 시 작업 리더가 수행. [[단조프레스-사양서]] 기준.

## 점검 항목

### 시작 전 (매 교대)
- [ ] 유압 탱크 유량 정상 (게이지 녹색 영역)
- [ ] 오일 누유 흔적 無
- [ ] E-STOP 3개소 복귀 위치 확인
- [ ] 광전센서 동작 테스트
- [ ] 양수 조작 키 정상

### 시간당 점검
- [ ] 유압 온도 60℃ 이하
- [ ] 펌프 진동 기준치 이내
- [ ] 소음 기준치 이내

### 이상 발생 시
즉시 E-STOP → [[안전표준-고온작업]] 대응 절차.
장비 지연 발생 시 [[2026Q1-단조지연-RCA]] 참조하여 유사 사례 확인.
