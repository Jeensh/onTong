# 단조프레스 사양서 — FP-210

> 2공장 3라인 주력 단조 설비. 안전 관리는 [[안전표준-고온작업]]을 따르며, 일상점검은 [[단조프레스-일상점검]] 참조.

| 항목 | 값 |
| ---- | -- |
| 모델 | FP-210 |
| 제조사 | 두산메카텍 |
| 도입 연도 | 2021년 |
| 위치 | 2공장 3라인 중앙 |
| 설비ID | EQ-FRG-FP210-03 |

## 기본 제원

- **최대압력: 2,500톤**
- 유압펌프: 160 kW × 2대
- 작동온도 범위: 상온 ~ 500℃
- 스트로크: 800 mm
- 사이클 타임: 45초/스트로크 (정상 운전)

## 안전 장치

- **긴급정지 E-STOP**: 좌 · 우 · 후면 3개소
- 양수 조작 안전 키 (양손 동시 필요)
- 광전센서 4조 (작업 영역 침입 감지)
- 오일 누유 센서 (저장 탱크 하단)
