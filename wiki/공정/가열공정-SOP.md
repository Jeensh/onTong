# 가열공정 SOP

> 2공장 3라인 가열공정 표준 작업 절차. 본 SOP는 [[가열로-온도-프로파일]] 현행본(v3)을 기준으로 합니다.

## 적용 범위
- 설비: [[가열로-사양서|DG-320 가열로]]
- 제품: A-Grade 슬래브, B-Grade 슬래브, K-Pro (2026-05 이후)

## 작업 단계

### 1단계 — 투입 준비
1. 전 공정(주조)에서 슬래브 도착 확인
2. 슬래브 표면 온도 80℃ 이하인지 확인
3. 이력 태그 스캔

### 2단계 — 온도 프로파일 진입
[[가열로-온도-프로파일]] 현행본 기준:
- 예열 **120℃ / 10분**
- 균열 **165℃ ±2℃ / 25분** (엄격 관리)
- 승온 **180℃ / 15분**

### 3단계 — 배출 및 다음 공정
- 균열 구간 ±2℃ 이탈 시 해당 로트 격리 → [[품질기준-균열관리]]
- 정상 배출은 [[단조공정-SOP]]로 이관

## 이상 대응
| 증상 | 대응 |
| ---- | ---- |
| Zone 센서 편차 2℃ 이상 | 일상점검 이상 보고 후 [[가열로-사양서]] 기준 조치 |
| 균열 온도 ±2℃ 초과 | 해당 로트 전수 검사 |
| 예열 도달 지연 | [[2025Q4-가열로-온도편차]] 유사 사례 참조 |
