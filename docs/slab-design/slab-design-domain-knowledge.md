## 0. 전체 개요

### 0-1. Slab 설계란?

고객 주문(코일)을 만들기 위해, **연주(연속 주조)에서 어떤 크기·무게의 Slab을 만들어야 하는지 자동으로 계산**하는 업무이다.

### 0-2. 전체 흐름

```
[고객 주문]
    ↓
[1. 두께 결정]      ← 연주설비 mold 두께
    ↓
[2. 1차 폭범위]     ← 열연 Edging 능력 + 설비 사양
    ↓
[3. 1차 길이범위]   ← 연주/열연 길이 제약
    ↓
[4. 1차 단중범위]   ← 두께×폭×길이×비중
    ↓
[5. 2차 단중하한]   ← 여러 제약 중 MAX
    ↓
[6. 2차 단중상한]   ← 여러 제약 중 MIN
    ↓
[7. 분할수 계산]    ← 최대 분할수 산정
    ↓
[8. 매수·목표단중]  ← Loop으로 최적값 결정
    ↓
[10. 2차 폭범위]    ← 단중 역산
    ↓
[12. Target폭]     ← 최종 폭 확정 (10mm 단위)
    ↓
[13. 3pass 재계산]  ← Edging 3pass 가능 여부
    ↓
[14. Target길이]   ← 최종 길이 확정
    ↓
[Slab 설계 완료]
```

### 0-3. 4가지 분류 (전체 박판공정계획에서)

박판공정계획에는 4가지 설계 방법이 있고, 본 문서는 **Coil 주문 설계방법** 중심으로 다룬다.

| 분류 | 품명 | 설명 |
|------|------|------|
| Coil 주문 (FAB 등) | FAB | 단중최대화 / 제품단중최대화 / 차등설계 / Edging최적화설계 |
| HR-Plate 주문 (FHE 등) | FHE | 단중최대화 / 부분여재최소화 / 부분여재최소화보정 |
| 하이밀 주문 | - | - |
| 외판Slab 주문 | - | - |

## 1. 핵심 용어 정리

### 1-1. 단중(單重) 계열

| 용어 | 영문 | 설명 |
|------|------|------|
| 단중 (UnitWeight) | UnitWeight | Slab 또는 코일 1개의 무게 (kg 단위) |
| 주문단중 | OrderWeight | 고객 주문 기준 코일 1개 무게 |
| Slab단중 | SlabWeight | Slab 1개의 무게 (분할 전 기준) |
| Target단중 | TargetWeight | 주문처리 시스템에서 입력되는 목표 단중 |
| 포장단중 | PackagingWeight | 포장 기준 단중 (보정상수 적용) |
| 포장단중범위(보정) | PackagingWeightCorrected | 보정상수 적용된 포장단중 범위 |
| 1차 단중범위 | PrimaryWeightRange | 두께/폭/길이 기반 단중 범위 |
| 2차 단중하한 | SecondaryWeightLower | 여러 제약 중 MAX |
| 2차 단중상한 | SecondaryWeightUpper | 여러 제약 중 MIN |
| 열연압연Min단중 | HRMinWeight | 열연 압연 가능 최소 단중 |
| 열연압연Max단중 | HRMaxWeight | 열연 압연 가능 최대 단중 |
| 냉연최소단중하한 | CSMMinWeight | 냉연 최소 단중 하한 |
| 임가공생산가능 단중상한 | OEMMaxWeight | 임가공 생산가능 단중 상한 |
| 설계대기량범위 | DesignCapacityRange | 연주 1회 주조 가능 무게 (예: 51~69톤) |
| 종합실수율 | CombinedYieldRate | 주문량 대비 실제 생산 가능 비율 |

### 1-2. 치수(Dimension) 계열

| 용어 | 영문 | 설명 |
|------|------|------|
| 폭 | Width | Slab/Coil의 폭 (mm) |
| 목표폭 (주문) | TargetWidth | 주문에서 요구하는 목표 폭 |
| 열연목표폭 | HRTargetWidth | 열연 단계의 목표 폭 |
| 길이 | Length | Slab/Coil 길이 (mm) |
| 두께 | Thickness | Slab의 두께 (연주설비 mold 두께와 동일) |
| 1차 폭범위 | PrimaryWidthRange | 1차 산정된 폭 범위 |
| 2차 폭범위 | SecondaryWidthRange | 단중 역산으로 재계산된 폭 범위 |
| Target Slab폭 | TargetSlabWidth | 최종 확정 Slab 폭 (10mm 단위) |
| 1차 길이범위 | PrimaryLengthRange | 1차 산정된 길이 범위 |
| 2차 길이범위 | SecondaryLengthRange | 단중 역산으로 재계산된 길이 범위 |

### 1-3. 설비(Equipment) 계열

| 용어 | 영문 | 설명 |
|------|------|------|
| 연주설비 | ContinuousCaster (CC) | 연속 주조 설비 (1연주, 2연주 등) |

| 임가공설비 | OEM | 임가공 설비 |
| 공장 | Factory | 광양 / 포항 |

### 1-4. 압연(Rolling) 개념

| 용어 | 영문 | 설명 |
|------|------|------|

### 1-5. 분할(Split) 개념

| 용어 | 영문 | 설명 |
|------|------|------|
| 분할수 | SplitCount | Slab 1개를 코일 N개로 나누는 수 |

| 분할수고려 단중상한 | SplitConsideredWeightUpper | 분할수 적용 후 단중 상한 |

### 1-6. 설계 방침

| 용어 | 영문 | 설명 |
|------|------|------|
| Slab설계방침 | SlabDesignPolicy | 단중최대화 vs 제품단중최대화 결정 정책 |
| Slab단중최대화 | SlabWeightMaximization | 무조건 Slab단중이 가장 큰 Case 선택 |
| 제품단중최대화 | ProductWeightMaximization | 단중만족율이 높은 Case 선택 |
| 단중만족율 | WeightSatisfactionRate | 분할수별 단중 매칭율 (%) |
| 단중만족상수 | WeightSatisfactionConstant | 단중최대화 vs 제품단중최대화 결정 임계값 (%) |
| 단중만족율차이 | SatisfactionRateDiff | MAX - MIN 만족율 |
| 3pass 가이드 | ThreePassGuide | 3pass 설계 옵션 |

### 1-7. 보정 개념

| 용어 | 영문 | 설명 |
|------|------|------|
| 포장단중보정상수 | PackagingCorrectionConst | 포장단중 하한/상한 보정용 |
| 압연Max보정값 | RollingMaxCorrection | 열연Max단중에 차감되는 보정값 |
| 주문단중 보정상수 | OrderWeightCorrection | 주문단중 보정용 (상한/하한) |
| 오버롤감축량 | OverrollReduction | 오버롤 감축량 (예: 0.6~2.0톤) |

#### 냉연최소단중하한 기준의 적용 룰

```

- 1FH의 주문항목 사용여부 NULL이므로 단중기준 적용시 열연목표값(1246.7/2.50) 사용 → 11000
```

### Step 2. 1차 폭범위 계산 ⭐

가장 핵심적인 계산. **연주 제조가능 폭범위, 열연 제조가능 폭범위, 열연 Edging능력 범위, 주문의 열연목표폭을 고려하여 공통 폭범위 산정**.

```
공식:
  1차 폭하한 산정 기준
    = max( 주문의 열연목표폭 + 열연Edging능력기준 하한,
           연주설비사양기준 하한폭,
           열연설비사양기준 하한폭 )

  1차 폭상한 산정 기준
    = min( 주문의 열연목표폭 + 열연Edging능력기준 상한,
           연주설비사양기준 상한폭,
           열연설비사양기준 상한폭 )

예제:
  열연목표폭 = 1529, Edging능력 하한 = 20, 상한 = 130

  1차 폭하한 계산:
    max( 1529 + 20, 900, 750 ) = max( 1549, 900, 750 ) = 1549
    → 결과값: 1550 (10mm 단위 절상)

  1차 폭상한 계산:
    min( 1529 + 130, 1950, 1650 ) = min( 1659, 1950, 1650 ) = 1650
    → 결과값: 1650 (10mm 단위 절사)

```

## 7. 주요 비즈니스 규칙 (Business Rules)

### Rule 1. 두께 불변성
> Slab 두께는 연주설비 mold 두께와 같으며, 설계 과정에서 변경되지 않는다.

### Rule 2. 단중 역산 원칙
> Step 10, 11에서 폭/길이를 단중으로 역산할 때, **단중은 고정값(Step 8 결과)**을 사용한다.

### Rule 3. 10mm 단위 절상/절사
> 폭과 길이는 항상 **10mm 단위**로 정렬된다.
> - 하한 산정: 절상(올림)
> - 상한 산정: 절사(내림)

### Rule 4. 비중 7.82 g/cm³ 일정
> 강종에 따라 미세 차이는 있으나, 본 시스템에서는 **7.82를 표준 비중**으로 사용.

### Rule 5. PO재 예외
> 냉연최소단중하한 적용 시 PO재(피클링/오일링재)는 제외된다.

### Rule 6. Target단중 입력 시 보정상수 미적용
> Target단중이 입력된 오더는 **포장단중 보정상수 상한 미적용**.

### Rule 7. 3pass 옵션 적용
> Slab설계방침에 3pass 가이드가 ON일 때 Step 13이 실행된다.

### Rule 8. 분할수 최소값 1
> 분할수가 0 이하가 되는 경우는 발생하지 않는다 (조건비교 검증).

### Rule 9. Slab단중최대화 vs 제품단중최대화 결정
> `단중만족율차이(MAX-MIN) > 단중만족상수` 일 때 → Slab단중 최대화
> 그렇지 않으면 → 제품단중 만족율 최대화

### Rule 10. 설계대기량 범위 만족 필요
> Step 8 Loop에서 `Slab단중 × 매수`가 설계대기량 범위 안에 들어와야 한다.
