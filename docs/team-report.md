onTong 프로젝트 현황 보고서
========================================

프로젝트명: onTong — 제조 SCM을 위한 지식 융합 멀티 에이전트 플랫폼
버전: 1.0.0
보고 일자: 2026-04-17


[프로젝트 개요]

onTong은 제조 SCM(Supply Chain Management) 현장의 흩어진 지식을 하나로 모으고,
AI가 이를 활용해 업무를 지원하는 플랫폼입니다.
위키 기반 지식 관리 · 레거시 코드-도메인 온톨로지 매핑 · 비즈니스 시뮬레이션을
하나의 웹 애플리케이션에 통합합니다.


========================================
1. Wiki — 지식 관리 & AI 질의응답
========================================

[핵심 기능]
  - 사내 문서를 웹에서 작성·편집·검색하는 Wiki 기반 파일시스템
  - AI Copilot(Hybrid RAG)에게 질문하면 키워드+의미 검색을 결합하여 관련 문서를 찾아 근거 기반 답변
  - 문서 간 충돌·중복을 AI가 자동 감지
  - 신뢰도 스코어링으로 오래되거나 검증되지 않은 문서를 자동 식별

[작업 내용]
  - Wiki 기반 파일시스템 구축 (마크다운 문서 폴더 구조 저장 + 메타데이터 자동 인덱싱)
  - 멀티포맷 뷰어 — Excel·PDF·PPT·이미지를 별도 프로그램 없이 웹에서 열람
  - AI Copilot 채팅 — Hybrid RAG로 문서를 찾고, LLM(Claude·GPT·Gemini 등)이 근거를 인용하며 실시간 스트리밍 답변
  - Skill 시스템 — 장애대응·보안점검 등 업무별 AI 행동 템플릿 정의, 반복 업무 자동화
  - 지식 그래프 — 문서 간 관련·인용·충돌 관계를 그래프로 시각화
  - 이미지 관리 — 중복 제거 + 어노테이션 편집
  - 권한 관리(RBAC) 구현 완료

[Tool · 기술]
  - Hybrid RAG — 키워드 검색 + AI 의미 검색을 결합하여 정확한 문서를 찾아 답변 생성
  - Skill 시스템 — 업무별 AI 행동 템플릿을 마크다운으로 정의·관리
  - Wiki 기반 파일시스템 — 마크다운 문서를 폴더 구조로 저장, 메타데이터 자동 인덱싱
  - LLM 멀티 프로바이더 — Claude, GPT, Gemini 등 여러 AI 모델을 상황에 맞게 전환 가능
  - 문서 충돌 감지 — 유사한 내용의 문서를 자동으로 찾아 중복·모순 경고
  - 신뢰도 스코어링 — 문서 최신성·인용 빈도·피드백을 종합하여 점수 산출
  - 지식 그래프 — 문서 간 관계를 그래프로 시각화

[이슈]
  - 대규모 확장 미착수 (현재 ~2K 문서 → 목표 10만+ 문서, 5,000+ 동시 사용자)
  - AI 첫 응답 지연 약 7.5초 → 목표 1~2초

[앞으로의 계획]
  - 대규모 문서 환경 대응 (검색 성능 최적화, 수평 확장)
  - AI 응답 속도 개선
  - 이미지 관리 데모 검증


========================================
2. 온톨로지 모델링 — 레거시 코드 분석 & 도메인 매핑
========================================

[핵심 기능]
  - Slab 설계 시스템(Spring Boot, JavaScript) 등 기존 SCM 레거시 소스코드를 코드 자동 파싱 Tool로 분석
  - Graph DB 기반 온톨로지 모델링으로 업무 도메인 표준(SCOR/ISA-95)과 코드를 시각적으로 연결·매핑
  - "이 코드를 바꾸면 어디에 영향이 가는지" 의존 관계를 추적

[작업 내용]
  - 한국어 NLP 영향도 분석 — "안전재고 계산 로직 변경하면?" 같은 자연어 질문으로 영향 범위를 그래프 탐색으로 파악
  - 파라메트릭 시뮬레이션 — 9개 SCM 엔티티 파라미터 조정 시 Before/After 비교 즉시 확인
  - 인터랙티브 매핑 워크벤치 — 좌측 업무 도메인 그래프 + 우측 소스코드 뷰어, 드래그&드롭으로 코드↔업무 연결
  - 코드 자동 파싱 — 소스코드에서 클래스·메서드·호출 관계 등 15종 구조를 자동 추출·시각화
  - SCOR/ISA-95 표준 온톨로지 템플릿(30+ 노드) 구현 완료

[Tool · 기술]
  - Graph DB 기반 온톨로지 모델링 — 코드의 의존 관계를 그래프 DB에 저장, 업무 도메인 표준과 매핑하여 영향도 추적
  - 코드 문서화 Tool — 소스코드를 자동 파싱하여 15종의 엔티티·관계를 추출, 시각적 탐색
  - 한국어 NLP 용어 해석 — 한국어 업무 용어를 코드 엔티티로 자동 매칭 (사전 + 유사도 + LLM 보완)
  - 인터랙티브 매핑 워크벤치 — 도메인 그래프 + 소스코드 뷰어를 나란히 놓고 드래그&드롭 연결

[이슈]
  - 현재 Java 파서만 구현 완료 (JavaScript/TypeScript 파서 확장 예정)
  - 로컬 환경에서 Graph DB 미실행 시 제한 모드 동작

[앞으로의 계획]
  - 실제 Slab 설계 시스템(Spring Boot · JavaScript) 소스코드 기반 온톨로지 모델링 적용
  - 실제 의존성 그래프 기반 영향도 분석 (현재 데모 데이터)
  - 코드 편집 샌드박스 (안전한 격리 환경에서 수정 테스트)
  - JavaScript/TypeScript 파서 확장
  - Section 3 시뮬레이션과 실 연동

3. 시뮬레이션 — Slab 설계 & AI 에이전트
========================================

[핵심 기능]
  - 열연 Slab 설계 파라미터를 3D 파라메트릭 시뮬레이터로 실시간 시각화·검증
  - AI 에이전트(ReAct 방식)가 스스로 도구를 선택·실행하며 설계 오류 진단·파급 분석·최적화를 자동 수행
  - 도메인 전문가가 코드 없이 자신만의 AI 에이전트를 만드는 커스텀 에이전트 빌더

[작업 내용]
  - AI 시나리오 에이전트 3종
      A: DG320 에러 진단 → AI가 주문 조회·설비 제약 확인·시뮬레이션을 순차 실행하여 폭 보정 제안
      B: Edging 용량 변경 시 영향받는 주문을 온톨로지 그래프 탐색으로 일괄 파악
      C: 단중 만족률이 최대가 되는 분할 수를 자동 탐색
  - 3D Slab 시뮬레이터 — 폭·두께·길이·단중·분할수·수율 6개 파라미터 슬라이더 조작
    → 3D 형상 실시간 변경 + SEQ 설계 단계별 pass/fail 즉시 반영
  - 커스텀 에이전트 빌더 — 대화 또는 폼으로 AI 에이전트 생성, 도구 선택하여 특화 분석 수행

[Tool · 기술]
  - AI 에이전트 (ReAct 방식) — AI가 도구를 선택·실행하며 단계적 문제 해결, 실시간 스트리밍으로 사고 과정 시각화
  - 3D 파라메트릭 시뮬레이터 — 6개 파라미터로 Slab 형상 실시간 조작, SEQ 설계 검증 즉시 반영
  - 온톨로지 그래프 시각화 — 주문-설비-Edging사양-Slab 간 관계를 그래프로 표시, AI 탐색 경로 애니메이션
  - 커스텀 에이전트 빌더 — 코드 없이 새로운 AI 에이전트를 만들고 도구를 선택하여 분석 수행

[이슈]
  - 현재 Mock 데이터 기반 동작 (5개 샘플 주문, 13개 온톨로지 노드)
  - Section 2 모델링과 실제 API 연동 미완료
  - 채팅 히스토리 브라우저 새로고침 시 초기화

[앞으로의 계획]
  - Section 2 실제 API 연동 (Mock → 실 데이터 전환)
  - 역계산 기능 (목표 중량에서 유효한 폭×길이 조합 탐색)
  - 다중 스냅샷 비교
  - Wiki SEQ 문서 연동
  - 채팅 세션 영속화
